# Design drafts

Static drafts, kept for reference rather than served. `data-origin89` is where the
data site's structure and its journal identity came from: the hero, the four
offerings, the evidence trail, the coverage chart and Buddy's place on the page.

The draft bakes a sample of the dataset into `data.js` so it can be opened from a
file. The site does not: it reads the same public endpoints anybody else would,
so what it shows is what is published rather than a snapshot of what once was.
